``` r
data("penguins", package = "palmerpenguins")
```

This dataset contains the following penguin species: Adelie, Gentoo, and
Chinstrap. These penguins are from the islands of Torgersen, Biscoe, and
Dream. The dataset also contains the bill length and depth in
millimeters, flipper length in millimeters, body mass in grams, sex and
year. The penguin dataset has 344 rows and 8 columns. The mean flipper
length is 200.9 mm.

``` r
penguin_plot =
ggplot2::ggplot(
  data = penguins,
  mapping = ggplot2::aes(
    x = bill_length_mm,
    y = flipper_length_mm,
    color = species
  )
) +
  ggplot2::geom_point()

penguin_plot
```
